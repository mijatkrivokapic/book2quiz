# Fully pinned to keep pip's dependency resolver fast and deterministic. Without
# these pins pip backtracks for many minutes: the newest wheels of torch (CUDA
# matrix), opencv/scikit-image/scipy (now require numpy 2), and transformers have
# huge version spaces. Versions below are a mutually-compatible set contemporaneous
# with docling 2.25.0 (Feb 2025), all accepting numpy 1.26.4.
